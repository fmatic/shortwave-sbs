# DX Intelligence Engine

> From schedules to intelligence.

The DX Intelligence Engine is a deterministic expert system that transforms
broadcast schedules into explainable DX insights.

## Principles

- Deterministic
- Explainable
- Modular
- Testable
- UI independent

## Architecture

Data Sources
      ↓
Analysts
      ↓
Decision Engine
      ↓
DX Assistant

Golden Rule

The DX Intelligence Engine must remain completely independent from the shortwave.sbs user interface. Every analyst operates solely on structured data and produces structured results.
